## Quick install

```sh
go install github.com/triptechtravel/slackbuzz-cli/cmd/slackbuzz@latest
```

Or via Homebrew:

```sh
brew install triptechtravel/tap/slackbuzz
```

See the [Installation](/slackbuzz-cli/installation/) page for all options.

## Quick start

```sh
# Create a Slack app with all required scopes
slackbuzz app create

# Check your inbox
slackbuzz activity

# Send a message
slackbuzz message send #general "Hello from the terminal!"
```

See the [Getting started](/slackbuzz-cli/getting-started/) guide for a full walkthrough.
